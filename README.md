# Tic-Tac-Toe in Python ⭕❌

זהו הפרויקט הראשון שלי במסגרת לימודי פיתוח AI ופייתון. משחק "איקס עיגול" קלאסי.

## 📝 תיאור הפרויקט
המשחק מאפשר לשני שחקנים לשחק אחד נגד השני על גבי לוח של 3x3. המערכת מנהלת את התורות, בודקת ניצחון או תיקו, ומוודאת ששחקנים לא יבחרו משבצות תפוסות.

## ✨ פיצ'רים מרכזיים
* **ממשק טרמינלי נקי:** תצוגה גרפית פשוטה של הלוח לאחר כל מהלך.
* **ולידציית קלט:** המשחק יודע לזהות אם הקלט תקין או אם המשבצת כבר תפוסה.
* **זיהוי מנצח:** בדיקה אוטומטית של שורות, עמודות ואלכסונים.
* **טיפול בתיקו:** המשחק מזהה מתי הלוח מלא ללא מנצח.
