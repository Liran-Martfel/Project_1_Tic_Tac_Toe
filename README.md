# Tic-Tac-Toe Python Project 🎮

## 📁 מבנה הפרויקט

הפרויקט מחולק ל-3 קבצים עיקריים המייצגים שלבי פיתוח שונים:

1.  **`TIC_TAC_TOE.py`** הליבה של הפרויקט. כולל את לוגיקת המשחק המלאה, כולל מימוש של הבונוס הראשון וחלק מהבונוס השני.
    
2.  **`TIC_TAC_TOE_FOR_ANIMATION.py`** גרסה מותאמת של לוגיקת המשחק. קובץ זה מכיל פונקציות תשתית ייעודיות שנועדו לאפשר אינטגרציה חלקה עם מערכת האנימציות (כהכנה לבונוס השלישי).

3.  **`animation.py`** השלב המתקדם ביותר (הבונוס השלישי). קובץ זה אחראי על הצד הויזואלי והנפשת המשחק, תוך שימוש בתשתיות שנבנו בקבצים הקודמים.
